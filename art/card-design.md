# 武学卡牌尺寸与图片规范

- 普通完整牌面：160 × 240 CSS 像素，宽高比 2:3。奖励、图鉴、商店、桌面手牌共用。
- 放大牌面：260 × 390 CSS 像素，宽高比 2:3。固定居中展示，头部关闭、底部确认区域单独布局。
- 窗口高度不大于 560 像素时，整个放大牌面等比缩至 75%，仍保持 2:3；高度不大于 430 / 350 像素时统一缩为 60% / 50%。不按内容分别变尺寸。
- 手机手牌：沿用固定底栏高度变量；1—10张在固定底栏内扇形叠放，同屏牌面等宽、等高；角度对称，点中抬起并置于最前。显示既有招式配图和横向牌名，点开显示260×390标准大牌面。
- 牌组、牌堆及图鉴缩略卡：统一2:3比例，最大140×210；窄屏两列，360像素及以上三列。点选可查看260×390完整牌面，返回保留列表位置。
- 普通牌名固定两行区域，插画固定 64 像素高；大牌名固定两行区域，插画固定 114 像素高。
- 效果说明区独立滚动，费用、牌名、配图、底部标记与出招确认保持固定。长效果不会撑开卡牌。
- 13 张原创主题插画按招式语义共享，覆盖 80 张武学与通用牌、气滞、心魔。图片是武学意境，不是玩家头像。
- 运行卡图：480 × 320 WebP，质量 72；原始生成 PNG 保存在本地 assets/cards/originals/。
- 运行人物立绘：480 像素高、保持透明，WebP 质量 76；原始 PNG 不变。
- 完整生成提示词：art/card-prompts.json。生成方式：内置 imagegen；压缩方式：cwebp。

## 奇物

30 件独立原生 SVG 物件图标存于 relic-art.js；随身栏为 28×28，奖励/商店为 72×72，列表为36—42像素，详情为 128×128，共用 128×128 的原始视框。金属、玉石、布料颜色保持一致，每件物品形状不同，无外部字体或图片依赖。
